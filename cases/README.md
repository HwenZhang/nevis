# NEVIS Cases

This directory stores lightweight case configuration files.

Run a regional case with:

```matlab
[tt, vv, info, state] = n2d_regional_template('nevis_regional');
```

Run an idealized case with:

```matlab
[tt, vv, info, state] = n2d_idealized_template('nevis_idealized');
```

To create a parameter-sweep case, copy an existing `*.m` config in this
directory, rename the file to the new `casename`, set `cfg.casename` to the
same name, and edit only config values. Regional cases should point to shared
data packages under `./data/datasets/` rather than copying heavy MAT files.

Regional ice-dynamics sweeps generated by `./srcgen/ice_dynamics_scripts.py`
can choose the inversion package and initial hydrology source explicitly, e.g.

```bash
python3 ./srcgen/ice_dynamics_scripts.py --overwrite \
  --inversion-file inversions/weertman_ns3_default/C_inversion_results.mat \
  --spinup-initial-hydrology-file inversions/weertman_ns3_default/velocity_inverted.mat
```

Run a configurable inversion with:

```matlab
[inv, vv_hydro, summary] = nevis_run_inversion('./cases/nevis_inversion.m');
```

Set `cfg.sliding_law` in the inversion config to `weertman` or
`regularized_coulomb`.
